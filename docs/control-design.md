# 拉力机旋钮屏控制设计

## 1. 当前硬件判断

- 照片外壳标识为 `FANRUI MZ58/60`，外观与凡睿 60 mm 圆形旋钮屏系列一致。
- 公开产品中最接近的是 2.1 英寸、480 x 480、触摸 + 旋转编码器、UART 接口型号。
- 外壳标识不是完整电子型号。照片中的主接口看起来为 6 针，与公开的 2.1 英寸 UART 型号一致，但仍不能由照片确定主控芯片、Giraffe BSP、UART 端口号或针脚顺序。
- USB-C 预计用于供电和工程下载；在拿到原厂针脚表前，不得把它当作电机通信口。

## 2. 页面与操作

### 主页面

- 顶部：连接状态、故障状态。
- 中央：当前主参数的大号数值和单位。
- 环形刻度：数值范围与当前设定。
- 左右箭头：触摸切换模式。
- 底部：实时力、速度或位置摘要。

### 交互约定

- 旋转：调整当前选中参数；慢转细调，快速转动可加速，但不得跨越安全上限。
- 短按旋钮：切换可调参数。
- 长按旋钮：确认进入运行；运行中长按只执行停止，不切换模式。
- 按住旋钮并旋转：切换输出模式。
- 触摸左右箭头：切换输出模式。参数切换和启停不提供触摸按钮。

## 3. 模式与协议映射

| UI 模式 | 命令 | 参数 |
| --- | --- | --- |
| 基础阻力 | `0x00` | 向心力、离心力、SSR |
| 弹簧 | `0x01` | 行程、峰值力 |
| 阻力带 | `0x14` | 静止长度、最大长度、峰值力、曲线系数 |
| 等速 | `0x11` | 目标速度、斜率 |
| 震动 | `0x04` | 幅值、频率 |
| 惯性 | `0x15` | 突破力 |
| 遥测 | `0x0E` | 21 字节状态响应 |

## 4. 控制状态机

```text
BOOT -> DISCONNECTED -> STOPPED -> EDITING -> ARMED -> RUNNING
            ^             ^                     |          |
            |             +------ STOP ---------+          |
            +---------------- FAULT <----------------------+
```

- `BOOT`：第一条 UART 帧发送 `02 0E 0E 03`，优先读取设备原始状态；读取成功后发送零输出停机帧，400 ms 无回包则延迟停机兜底。
- `DISCONNECTED`：允许编辑参数；启动后立即发送所选模式并等待遥测确认。
- `STOPPED`：收到有效遥测但未使能输出。
- `EDITING`：旋转或触摸改变本地参数，参数只保存在内存。
- `ARMED`：已发出当前模式指令，等待有效遥测；400 ms 内无回包则停机并进入故障。
- `RUNNING`：周期发送最新设定并轮询遥测。
- `FAULT`：校验错误连续出现、遥测超时、温度/电压越界或主板报告故障时进入；只能回到 `STOPPED`。

## 5. 通信任务

- UART 参数暂按 115200、8N1；电机文档只明确了 115200，8N1 需实机确认。
- UI 事件不直接阻塞发送，只更新共享设定并投递到通信任务。
- 上电立即发送 `02 0E 0E 03` 作为第一帧，取得状态后再发送安全停机帧；之后每 50 ms 定时查询。
- 参数更新周期为 40 ms；遥测轮询为 20 Hz。
- 接收端按命令对应的固定帧长解析，不能只寻找 `0x03`，因为负载内部也可能出现起止字节值。
- 下发命令验证并生成完整 XOR；V3/V5 反馈帧只强制验证起始字节、命令、固定 21 字节长度和结束字节。反馈 CHK 已知不可靠，只记录诊断信息，不能据此丢帧。
- 运行时通信超时建议 300-500 ms；最终必须由电机主板固件实现失联降力/断使能。

## 6. 暂定 UI 安全上限

协议允许最大力为 800.0 N（约 179.8 lb），当前 UI 使用 lb：

- 当前最大力：50.0 lb（发送值约 222.4 N）。
- 单格：1.0 lb；快速旋转最高加速到 5.0 lb/格。
- 所有力相关设定和遥测显示为 lb，发送时转换为协议的 0.1 N。
- 模式切换前强制停止。
- 上电、复位、重连后始终回到停止和零力。
- 在确认主板停机语义前，不把 `SSR=false` 或“发送零值”视为可靠急停。

## 7. 接入 Giraffe 工程所需资料

1. 旋钮屏完整电子型号或采购规格书。
2. 6 针主接口的正式定义与 UART 逻辑电平。
3. 对应芯片/系统的 Giraffe 示例工程或 BSP。
4. 编码器顺/逆时针和按压事件的官方 API 或例程。
5. Giraffe IDE 生成的空白 480 x 480 工程。
6. 电机主板 TTL UART 引脚；若只有 USB 串口，需要 USB Host 网关。
