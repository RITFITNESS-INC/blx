# V3/V5 协议适配结论

依据《V3-V5通信协议说明》，本工程采用以下处理：

1. UART 打开并安装接收回调后，第一条发送帧固定为 `02 0E 0E 03`。
2. 反馈必须是 21 字节，且满足帧头 `02`、命令 `0E`、帧尾 `03`。
3. 反馈中的 `state` 原始字节优先保存并显示；状态名称的确切数值未在文档中给出，当前不做猜测映射。
4. 文档说明反馈 CHK 可能只覆盖 CMD 和前四个载荷字节，并要求解析时不要依赖 CHK。程序兼容记录完整 XOR、短 XOR 和不匹配三种情况，但都不因 CHK 单独拒绝结构正确的反馈。
5. 首次读取状态成功后发送基础模式零力、SSR 关闭帧，建立本次上电的停止基线。
6. 首次状态读取超过 400 ms 仍无响应时，发送一次零输出停机兜底并继续轮询；在读到有效状态前禁止启动。
7. 运行中反馈超过 400 ms 中断，立即发送零输出停机帧并进入通信故障。

文档列出的 IDLE、RUNNING、POSITION、BENCH_TEST 只有名称，没有可靠数值。拿到电机固件团队给出的枚举值后，才能把顶部的 `设备0xXX` 替换为中文状态名称。
